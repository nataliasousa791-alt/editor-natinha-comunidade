Robô Remotion experimental (separado)

Este modo executa o robô cinematográfico experimental de forma independente, sem aproveitar os cortes escolhidos pelo Natinha original. Para unir as habilidades dos dois, use a opção acima.

Resultados padrão: Editor Natinha → Resultados → Remotion. Nunca exporta automaticamente para o Robô Postador.

Ajustes avançados para trechos específicos (opcional)
Sem autorização, o modo é offline: aproveita regras, transcrição local e clipes já existentes. Uma edição pode ficar visualmente mais simples. Nenhum serviço pago é acionado por esta integração.

🔗 Natinha original + Remotion

Use a edição que o Natinha original já fez: cortes inteligentes, voz limpa, palavras sincronizadas e B-rolls. O Remotion cria o acabamento cinematográfico por cima. Os arquivos originais não são alterados.
